# BYD Horizon Club 🏎️💨

Welcome to the **BYD Horizon Club** Web Application! This platform provides a state-of-the-art fractional electric vehicle co-ownership, investment, and smart delivery tracking ecosystem. Fully optimized as a high-performance precision Bento UI/UX, users can browse luxurious fleets, obtain protection plans, refer partners, participate in engaging gamified quizzes, and track live global fleet logistics.
